\section{Project Overview}
The Dog Shelter Management System is a centralized platform designed to help animal shelters manage dog intake, medical records, and adoption processes efficiently. The system allows staff to track dog information, update records, and manage adoption applications in an organized manner.

Set up repository, Software Requirements Specification (SRS), and Software Design Document (SDD).

Implement Dog Intake System and Dog Status Tracking.

\subsection{2nd Checkpoint}
Implement Medical Records, Adoption Management System, and Admin Dashboard.

Perform testing, bug fixes, and finalize the system.

\section{Goals and Purpose}
The Dog Shelter Management System is designed to improve organization within animal shelters by providing a centralized platform to manage dog intake, medical records, and adoption processes. The system reduces manual tracking errors and streamlines daily operations for staff.

\section{How to Download and Run}

\subsection{Clone the Repository}
\begin{verbatim}
git clone https://github.com/Yumcha113/CS3338_FinalProject.git
cd CS3338_FinalProject
\end{verbatim}

\subsection{Run with Docker}
Make sure Docker is installed and running, then execute:
\begin{verbatim}
docker compose up --build
\end{verbatim}

\subsection{Access the Application}
\begin{itemize}
    \item Frontend: http://localhost:3000
    \item Backend: http://localhost:5001
    \item Database Test: http://localhost:5001/db-test
\end{itemize}

\subsection{Stopping the Application}
Press CTRL + C in the terminal, then run:
\begin{verbatim}
docker compose down
\end{verbatim}

\subsection{Key Takeaways}

\section{Core Features}

\subsection{Dog Intake System}
Allows staff to add new dogs and store basic information such as name, breed, age, and arrival date.

\subsection{Medical Records System}
Enables tracking of vaccinations, treatments, and overall health status of each dog.

\subsection{Adoption Management System}
Allows users to submit adoption applications and staff to review, approve, or reject them.

\subsection{Dog Status Tracking}
Tracks whether a dog is available, pending adoption, or adopted.

\subsection{Admin Dashboard}
Provides staff with a centralized interface to manage dogs, records, and applications.

\section{How to Use the System}
\begin{itemize}
    \item Staff can add and update dog information
    \item Medical records can be updated as treatments occur
    \item Adoption applications can be reviewed and processed
    \item Dog status is updated based on adoption progress
\end{itemize}
